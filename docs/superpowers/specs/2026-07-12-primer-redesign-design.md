# 原理章(primer)重新定义:设计过的数学表达,而非源码解读

日期:2026-07-12
状态:哲学已获用户确认;12 章评审完成(2 rewrite / 10 modify / 0 keep)——现行 primer 无一达标
动机:用户指出原理章"还在生硬讲解源码;论文与真实实现未必一样;现在数学没讲懂、看代码又一头雾水"。评审 12 章证实:每章 25–50% 篇幅是配对实现章的源码走读,核心机制退回稠密下标代数,缺"一眼看清结构"的架构图。这也是全书"割裂感"的总根源——把源码解读硬焊在数学表达上。

## 1. 原理章的天职(唯一标准)
**把数学/原理设计成最清晰的表达,让读者一眼看清本质、降低理解门槛,但不失深度。** 源码落地属于隔壁配对的实现章(MLA 原理 ch21 → 落地 ch22;FA 原理 → ch25;量化原理 → ch28…)。

## 2. 表达设计三段式(每个 core 机制)
1. **先亮洞见**:一句话/一个直觉/一条律,先把"为什么这样是对的/省的"点破(如 MLA 吸收:"$W^{UK}$ 是静态的 → 折进 query → 永不物化 key")。
2. **用最简记号 + 一张架构图暴露本质**:去掉与本质无关的下标;画**结构/架构图**(哪个矩阵吸进哪个、吸收前 vs 吸收后;⊕ 算子的多副面孔并置;误差沿 $H^{-1}$ 列扇出),让人**一眼看懂**。架构图 ≠ 数值相等图。
3. **再补严谨**:完整推导/证明/边界移进 `> 严谨` 折叠块(callout),给深度但不挡主线。

## 2.4.5 递归讲透纪律(2026-07-14 用户抓 ch23 NSA「等于没讲」后追加——密度 ≠ 删深度)
密度纪律曾被执行成「删前置机制」:ch23 把 DSA 依赖的 NSA 砍到只剩比喻+门控公式——压缩支路怎么压(Eq.7 的 φ)、滑窗为什么存在(防局部捷径垄断梯度)、「原生可训练」靠什么(复用压缩分数=离散选择的可微之桥)全部消失,承重的 Eq.(9)-(12) 被埋进折叠框。三条硬规则:
- **递归展开**(苏剑林式深入):机制链按「问题→设计决策→该决策引出的新问题→下一个决策…」层层追问展开。每个支路/组件必须答出「它解决前一步的哪个失败模式、为什么这样解是对的」——只给比喻和结论、不给机制推理 = 等于没讲。
- **承重内容必须在正文**:本章后继机制所依赖的前置(如 DSA 依赖 NSA 的打分谱系)、以及「为什么这样设计」的论证,一律正文展开;「> 严谨」折叠框只收**验证性**(数值复核/边界)、**旁支**(被后继弃用且不影响主线)内容。判据:跳过折叠框后读者还能答出每个设计决策的为什么,才允许折叠。
- **高密度=每句话推进机制或绑定数字**,靠删比喻/套话/重复实现,**不靠删内容**。一段话删掉后读者答不出「为什么」了,就删错了。

## 2.4 信息密度纪律(2026-07-13 用户追加,ch21 两版对比后定)
- **数学是主角,不避讳公式**:公式信息密度高,推导链直接写、解说紧凑(参照苏剑林/科学空间 kexue.fm 的行文密度)。「先亮洞见」不等于先铺三段散文——洞见本身常常就是一行等价式/一个不变量。
- **比喻预算:每个机制至多一个短句**,只准点破洞见、不准替代推导。ch21 教训:名片墙/图纸零件/垫片/房间握手/敌人解药一章挤七八个比喻,信息密度反而被稀释。
- **点透深度优先于扩写**:最值钱的是「等价视角」类洞见(如 MLA decode 形态 ≡ head_dim=576 的 MQA;吸收=重排计算次序而非物化融合矩阵,3.0× 差距;吸收命门是「中间块常量性」而非结合律)。
- **写作模型**:原理章 writer 用 fable5(chapter-pipeline/primer-uplift 已改默认;ch21 对比验证)。

## 2.5 顿悟图方法(图解的核心——统一模式,非模板)
原理章是**图解**:图是主角、文字是解说词。但目标不是"画得准/全"(那是参考地图),而是**让核心洞见"啪"地击中读者(醍醐灌顶)**。准确 ≠ 顿悟。每章一张**顿悟图作头图**,方法五步:
1. **锚定"那一下"**:这个算法看完只需记住的**一个反直觉洞见**(不是数据流)。**一图只锚一个"那一下"**——塞两个洞见会互相稀释单拳(实测教训:MLA 头图曾把"压缩落差"+"权重吸收"塞一张,压缩那一拳被稀释)。MLA 头图=**纯压缩落差**("以为要存一整摞 K/V,其实只存一根 576 的 latent,57× 更小"),权重吸收("镜头挪到 query、连放大都省")留给它**自己的 zoom-in 图**。多个洞见=多张图,各打各的一拳。
2. **落差揭示**:顿悟几乎总来自**反转对比**——先"朴素做法(贵/笨)"再啪地"其实(省/巧)";图的视觉主轴就是这落差(宽 vs 窄、多次 vs 一次、物化 vs 不物化)。
3. **削到只剩本质**:删掉一切与"那一下"无关的枝节;顿悟靠**空**不靠全。完整数据流架构图退居**次要参考图**(博客那种,准确、能查)。
4. **通感的空间隐喻**:MLA 镜头挪位、FA 流水不落地、EAGLE 特征草图接龙——空间隐喻直接映射概念。
5. **量化落差可见**:关键数字做成视觉尺度(KV 缓存 $16384$ vs $512$ 的宽度差=32×,直接量在图上)。

**统一 = 方法 + 视觉语言 + 顿悟门,不是统一模板**:每算法的顿悟图**定制**(否则全长一样、无一顿悟),但共用①本方法;②一套视觉语言(svg-diagram「架构图/顿悟图参考模板」:色区分角色/维度标注/落差箭头/关键高亮);③**顿悟门**评审:看图 5 秒,核心洞见有没有被击中?没击中就打回(判"顿没顿",不是"画得对不对")。头图=顿悟图;完整架构图=次要参考。

## 3. 源码纪律(反"割裂感")
- 原理章里源码**至多一句「落地见第 N 章」指路**;不做完整函数签名走读、不解读与讲清原理无关的管线/格式/dispatch 代码。
- 唯一可留的源码:**能直接对上某条数学公式的 2–3 行核心**(如 merge_attn_states 的加权三行),且必在出现处绑回其数学符号。
- **禁 float64 舍入仪式**:"代数恒等,浮点差 ~1e-16"集中成一句总声明,数值表不再逐处复述。
- **禁命名错配裸奔**:凡引代码名(decode_k_nope),出现处即注"就是 $c^{KV}$"——但更该做的是根本不引它,把版面还给数学。
