## 画法要素（必须继承）

1. **泳道对偶**：API 进程内竖线分左右——右=下行（render→InputProcessor→assign_request_id→add_request），左=上行（output_handler→process_outputs→收集器×N→SSE）。下行/上行各是一条**方法名级**的链。
2. **多用户**：3 个 user 并排 + 3 个 Request Output Collector 并排（一一对应）+ sse 双向标注。
3. **中间带独立成框**：AsyncMpClient 大框横在两进程之间，内部 add_request_async（右，接下行）/get_output_async（左，接上行）双通道。**进程边界（zmq+msgpack）**大字标注在带左侧。
4. **引擎侧刻意简略**：只有三框——右（input_queue+DEALER+队列图标）、中（scheduler→execute→sample→update 循环四段横排+段间小箭头）、左（output_queue+PUSH+队列图标）。**不放**调度器细节/KV/执行臂——那些是 zoom-in 的事。
5. **队列图标**：三个小竖条 ▐█▌▐█▌▐█▌ 表示 queue。
6. **两条贯穿长箭头**：EngineCoreRequest（右路下行穿三段）、EngineCoreOutputs（左路上行穿三段）。
7. 框=浅色圆角矩形+黑边（excalidraw 手绘风），文字居中，箭头细黑。
